很多现实问题本质上是一个数学问题：在满足一系列约束的前提下，让某个目标最大化或最小化。**求解器（Solver）**就是在海量可行解中自动寻找最优解的引擎。

## 一、什么是求解器

求解器接收一个**数学优化模型**（变量、目标函数、约束条件），返回最优或近似最优解：

```text
minimize   cost(x)
subject to 约束条件(x)
```

它把"人肉枚举 + 拍脑袋决策"变为"精确计算 + 可证明最优"，是运筹学（OR）落地的核心工具。

## 二、常见问题类型

| 类型 | 变量特征 | 典型场景 |
|---|---|---|
| 线性规划 LP | 连续变量、线性目标/约束 | 配料、运输、生产计划 |
| 整数规划 ILP | 变量取整数 | 选址、装箱、设备选型 |
| 混合整数规划 MIP | 部分整数、部分连续 | 生产调度、排班 |
| 约束满足 CSP | 满足约束即可 | 排课、任务分配 |
| 组合优化 | 离散搜索 | 路径规划、车辆调度 |

其中很多组合问题属于 NP-Hard，规模稍大就无法穷举，正是求解器算法（分支定界、割平面、启发式）大显身手之处。

## 三、主流求解器

| 求解器 | 类型 | 特点 |
|---|---|---|
| Gurobi | 商业 | MIP 性能顶尖，学术免费 |
| CPLEX | 商业 | IBM 出品，成熟稳定 |
| OR-Tools | 开源 | Google，约束编程 + 路线规划 |
| SCIP | 开源（学术） | 非商业免费，MIP/CSP 强 |
| HiGHS | 开源 | 高性能 LP/MIP，活跃发展 |

> 选型建议：商业求解器（Gurobi/CPLEX）性能与支持最好；开源场景可选 OR-Tools 与 HiGHS，兼顾成本与能力。
{: .prompt-tip }

## 四、典型应用场景

- **生产排程**：多产线、多订单、多约束下的作业排序与资源分配。
- **物流路径**：车辆路径问题（VRP）、配送调度。
- **资源调度**：机房/云资源、电力、班次编排。
- **投资组合**：风险与收益的量化平衡。

求解器与 AI 也日益结合：用机器学习预测需求/时长，再用求解器做决策优化，"预测 + 优化"是工业智能的经典范式。

## 五、一个最小示例（OR-Tools）

下面用 Python + OR-Tools 解一个极简的"两任务两台机器"调度问题，示意建模思路：

```python
from ortools.sat.python import cp_model

model = cp_model.CpModel()
# 变量：两个任务的开始时间
start_a = model.new_int_var(0, 10, "start_a")
start_b = model.new_int_var(0, 10, "start_b")
# 约束：两任务不能同时占用同一台机器（互斥）
model.add_no_overlap([...])
# 目标：最小化总完工时间
model.minimize(max(start_a + 3, start_b + 2))

solver = cp_model.CpSolver()
status = solver.solve(model)
```

> 建模的关键是把业务规则准确翻译为"变量 + 约束 + 目标"；模型建错，求解再快也徒劳。
{: .prompt-warning }

## 小结

求解器把复杂的决策问题交给数学与算法，在排程、调度、路径与资源分配中创造真实价值。配合机器学习的预测能力，"AI + 求解器"正在成为工业决策优化的标准组合。
